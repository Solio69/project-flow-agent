# Дизайн-система Project Flow Agent

Обновление экрана «Текущие задачи» согласовано 25 ноября 2026 года. Светлая и тёмная темы используют один интерфейс с разными палитрами.

- [Светлый макет](current-tasks/light.html)
- [Тёмный макет](current-tasks/dark.html)

Оба HTML-файла открываются напрямую в браузере и используют демонстрационные данные. При автономном открытии для иконок действий используются встроенные резервные символы. Эмодзи проектов отображаются системным шрифтом.

### Производные оттенки

- Шапка проекта смешивает 29% цвета проекта с `--pfa-surface`. При наведении на задачу 16% акцентного цвета смешивается с `--pfa-task-surface` по всей ширине строки.
- У «Сегодня» свой розовый акцент для шапки, контура и наведения. Поле названия в обеих темах использует тот же расчёт с лавандовым акцентом темы. Для границы берётся 38% акцента на `--pfa-surface`, для мягкой тени — 24% акцента с параметрами `0 2px 12px`. При системной повышенной контрастности появляется контур цвета `Highlight`.
- Контур круглых кнопок в списках использует 28% `--pfa-control-ink`, при наведении — 50%. Для нейтральной подсветки кнопок и меню используется 7% этого цвета. Контур верхних кнопок строится на 50% `--pfa-ui-accent` и усиливается при наведении.
- Пустые списки и подписи под полями используют `--pfa-caption`, смесь 88% `--pfa-muted` с фоном списка задач. Выбранный диапазон календаря использует 10% `--pfa-ui-accent` на той же поверхности.

## Типографика

Основной стек — `system-ui, "Segoe UI", sans-serif`. Базовая высота строки — `1.45`. Для эмодзи используется `"Segoe UI Emoji", "Apple Color Emoji", "Noto Color Emoji", sans-serif`.

| Элемент | Размер | Насыщенность |
| --- | --- | --- |
| Заголовок страницы | `clamp(22px, 4.8vw, 29px)` | 650, межбуквенный интервал `-0.035em` |
| Заголовки проектов, «Сегодня» и месяца в календаре | 14 px | 650 |
| Заголовки диалогов | 16 px | 650 |
| Названия задач и пояснения в диалогах | 14 px | 400. Название проекта в строке задачи — 600 |
| Кнопки и пункты меню | 13 px | 400 для меню, 500 для кнопок, 600 для верхних кнопок и подтверждений |
| Значение поля ввода | 16 px | 400 |
| Подпись под полем, дни недели и пояснения в меню | 12 px | 400 |

Числа календаря набираются табличными цифрами размером 13 px. Эмодзи проектов имеют размер 16 px, на узком экране — 15 px.

## Компоненты и состояния

| Компонент | Визуальное правило |
| --- | --- |
| Фон экрана | Прозрачный в обеих темах. За карточками виден фон заметки или контейнера, в который встроен экран |
| Карточка проекта | Цветная шапка, эмодзи и отдельные действия. Шеврон слева сворачивает список. Круглые кнопки добавления и архивации расположены справа |
| Строка задачи | Высота от 44 px. Чекбокс круглый, визуальный размер 18 px. Разделитель совпадает с нижней границей подсветки. Название подчёркивается при наведении. У выполненной задачи название зачёркнуто и показано вторичным цветом. Ручка перетаскивания показывается при двух и более незавершённых задачах в списке |
| Пустой список | Сообщение по центру на фоне задач, цвет `--pfa-caption`. Если в списке остались только скрытые выполненные строки, отображается «Все задачи выполнены» |
| Верхние кнопки | Фон списка задач, скругление 10 px и контур в цвет общего акцента. Крестик очистки появляется рядом с выбранным периодом |
| Переключатель видимости выполненных | Расположен рядом с переносом в историю и включён при первом открытии. После перезапуска восстанавливается последнее положение. Подпись «Скрыть выполненные» меняется на «Показать выполненные», когда строки скрыты. Во всех списках выполненные находятся под незавершёнными, от недавно выполненных к более ранним. Перенос в историю учитывает скрытые задачи |
| Календарь | Один календарь для начала и конца периода. У границ диапазона есть контур. Пустое состояние кнопки называется «Выбрать даты» |
| Диалог | Фон списка задач, скругление 16 px и мягкая тень `0 12px 36px`. Вся шапка окрашена фоном страницы. Кнопки подтверждения контурные, у удаления задачи — лёгкая заливка |
| Переименование задачи | «Сохранить» занимает всю доступную ширину внизу. Крестик справа вверху, клик по подложке и Escape закрывают форму без сохранения |
| Поле названия | Высота от 36 px, скругление 8 px. Подпись находится под полем. При переименовании курсор стоит в конце текущего названия |
| Меню задачи | Фон списка задач, тонкие разделители и тень `0 8px 24px`. Иконки и пояснения подчинены общему акценту и вторичному тексту |
| Перенос задачи | Из меню «…» открывается окно с названием задачи, исходным проектом и карточками других проектов текущего периода. Выбор один, кнопка «Перенести» занимает всю доступную ширину |

Скругление карточек — 14 px. У круглых кнопок размер 34 px для мыши и 44 px для сенсорного ввода. Боковой отступ содержимого карточек — 12 px, на экранах до 410 px — 8 px.
