# Локальный запуск каркаса

Открой PowerShell в корне репозитория. Используй Node.js 22 или новее.

```powershell
npm ci
npm test
npm run build
```

Готовый плагин состоит из `dist/main.js`, `dist/manifest.json` и `dist/styles.css`.

## Запуск из VS Code

Открой корень репозитория в VS Code и запусти **dev:obsidian** кнопкой ▶
в панели **NPM Scripts**. При запуске из новой копии репозитория создай
в его корне файл `.env.local` с путём к хранилищу, содержащему `.obsidian`.

```dotenv
PFA_OBSIDIAN_VAULT='D:\путь\к\хранилищу'
```

Watch собирает плагин в `.obsidian/plugins/project-flow-agent/` этого хранилища.
Оставь терминал открытым, чтобы сборка подхватывала правки. В Obsidian открой
«Настройки → Сторонние плагины → Установленные плагины», обнови список
и включи **Project Flow Agent**. Если при первой установке плагина в списке
ещё нет, закрой и снова открой Obsidian с тем же хранилищем. После включения
плагина на левой ленте появится кнопка **Текущие задачи**.

Для автоматического обновления установи и включи **Hot Reload** в том же хранилище.
Команда разработки создаёт маркер `.hotreload` в папке нашего плагина. Чтобы проверить
обновление, временно измени текст в `src/current-tasks/CurrentTasks.tsx`, сохрани файл
и посмотри на вкладку. Если она закрылась при перезагрузке плагина, открой её с ленты.
Остановить watch можно через Ctrl+C.

Из терминала тот же режим запускается через `npm run dev:obsidian`.
Чтобы разово выбрать другой каталог, используй `npm run dev -- "D:\путь\к\хранилищу"`.

Для разовой установки скопируй три файла из `dist/` в
`.obsidian/plugins/project-flow-agent/` и включи плагин.
