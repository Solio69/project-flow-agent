# Управление видом текущих задач

**Ветка** `feature/add-and-change-buttons-in-current-tasks`

**Карта проекта** «Текущие задачи», управление списками на странице.

## Согласованный объём

Повторить [светлый](../../docs/design/current-tasks/light.html) и
[тёмный](../../docs/design/current-tasks/dark.html) макеты. В верхней панели
есть группа из трёх иконок с общей рамкой. Иконка глаза меняет видимость
выполненных, иконка сворачивания управляет карточками проектов. «Статистика»
показана как недоступное действие по макету. «Наверх» прокручивает вкладку.

## Сценарии и критерии приёмки

- **US1 / FR-001** При открытом списке хотя бы одного проекта групповая
  кнопка сворачивает все карточки проектов. Когда все они свёрнуты,
  кнопка разворачивает их. Индивидуальные стрелки работают. Блок «Сегодня»
  остаётся открытым. При отсутствии проектов групповая кнопка недоступна.
- **US2 / FR-002** Последнее состояние каждой карточки и видимость
  выполненных восстанавливаются после закрытия вкладки и перезапуска
  Obsidian. Незнакомая карточка открыта по умолчанию. Состояние хранится в
  настройках плагина. Карточки с общей заметкой и разными заголовками
  сохраняют свои состояния после перестановки. Ранее сохранённые ключи
  переносятся при первом чтении списка по доступному порядку карточек.
  Markdown заметок сохраняется.
- **US3 / FR-003** «Наверх» появляется при прокрутке вкладки и располагается
  по центру её нижнего края. Кнопка возвращает к началу вкладки, учитывает
  системную настройку уменьшения движения и доступна с клавиатуры. Поверх
  списка у кнопки непрозрачный фон в оттенке блока «Сегодня». Под списком
  фон прозрачный. При пересечении с меню задачи меню остаётся поверх
  кнопки и получает нажатие.
- **US4 / FR-004** При переносе между «Сегодня» и проектом вкладка остаётся
  у исходного блока. Клавиатурный фокус сохраняется в нём без автопрокрутки,
  даже после перемещения последней задачи или при свёрнутом проекте
  назначения. При отказе фокус остаётся на исходной стрелке.

Проверить состояние смешанного списка, массовое и ручное сворачивание,
восстановление двух настроек, узкую вкладку и обе темы.
