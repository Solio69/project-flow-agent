# План управления видом текущих задач

1. Объединить настройки вида и запись через `saveData()`. Проверить
   сохранение существующих настроек при быстрых изменениях обеих функций.
2. Перенести панель управления по обоим макетам. Использовать состояние
   проекта для индивидуального и массового сворачивания.
3. Подключить «Наверх» к прокрутке вкладки, проверить расположение и фокус.
4. Прогнать проверку через публичный вход плагина на тестовых данных,
   светлую и тёмную темы в Chromium, сборку и ревью.

Настройки вида принадлежат плагину. Текущие задачи и проекты по-прежнему
читаются из Markdown, команды вида не записывают заметки.
