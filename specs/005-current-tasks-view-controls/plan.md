# План управления видом текущих задач

1. Объединить настройки вида и запись через `saveData()`. Проверить
   сохранение существующих настроек при быстрых изменениях обеих функций.
2. Перенести панель управления по обоим макетам. Использовать состояние
   проекта для индивидуального и массового сворачивания.
3. Подключить «Наверх» к прокрутке вкладки, проверить расположение и фокус.
4. Прогнать проверку через публичный вход плагина на тестовых данных,
   светлую и тёмную темы в Chromium, сборку и ревью.
5. Воспроизвести скачок при возврате из «Сегодня» в далёкий проект.
   Восстанавливать фокус в исходном блоке в обоих направлениях.
   Проверить мышь, Enter, свёрнутый проект и обе исходные позиции.
6. В тесте запуска плагина загрузить прежние ключи проекта, переставить
   два его заголовка и повторно открыть список. Сверить настройки,
   восстановленное сворачивание и отсутствие записи в Markdown.
7. Проверить назначение клика в зоне пересечения меню и кнопки «Наверх»
   на короткой узкой вкладке в обеих темах. Сверить порядок слоёв в макетах.
   Проверить, что подписка получает `{ passive: true }` из именованной
   константы в плагине и в обоих макетах.

Настройки вида принадлежат плагину. Текущие задачи и проекты по-прежнему
читаются из Markdown, команды вида не записывают заметки.
