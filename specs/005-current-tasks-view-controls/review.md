# Ревью управления видом текущих задач

Проверен локальный diff относительно `f7ca728`. Два поля настроек
используют одну последовательность сохранения и сохраняют прочие значения
плагина. Карточка получает стабильный ключ по пути проектной заметки.
«Сегодня» остаётся открытым, а после переноса раскрывается карточка
назначения, если в неё добавилась задача.

Панель соответствует макетам. «Наверх» получает контейнер конкретной
вкладки. Он освобождает подписку при закрытии, учитывает уменьшение
движения и возвращает фокус на заголовок при активации с клавиатуры.

Проверены границы FSD, настройки, пробелы и область изменений. Проверка
в рабочем Obsidian остаётся частью пользовательской приёмки.

## Ревью после завершения разработки

Проверен весь локальный diff ветки `feature/add-and-change-buttons-in-current-tasks`
относительно `f7ca728`, включая новые файлы.

- **Средняя.** Две карточки с общей заметкой проекта получали один ключ
  настройки. Закрытие одной закрывало обе. В
  [`TasksList`](../../src/pages/current-tasks/ui/TasksList/TasksList.tsx)
  у первой карточки сохранён прежний ключ по пути, а ключи дополнительных
  карточек различаются по порядку появления. Индивидуальные стрелки,
  групповая кнопка и раскрытие после переноса используют те же ключи.
- **Низкая.** В обоих интерактивных макетах «Наверх» отображалась до
  прокрутки и не обрабатывала нажатие. В
  [светлом](../../docs/design/current-tasks/light.html) и
  [тёмном](../../docs/design/current-tasks/dark.html) макетах кнопка
  появляется после прокрутки, возвращает фокус к заголовку при активации
  с клавиатуры и учитывает настройку уменьшения движения.
- **Кодстайл.** Настройки вида собраны в отдельном модуле с публичным
  `index.ts`. Кнопки панели используют общую разметку, настройки фокуса
  переиспользуются из `shared/lib/dom`, проверка строк использует общий
  предикат. Данные проверки вынесены в фикстуры.

Проверены сохранение настроек без записи в Markdown, границы FSD, кодстайл
и отсутствие секретов в diff. Результаты повторных запусков записаны
в [verification.md](verification.md).

- **Средняя.** Раскрытие диагностики сдвигало список при неизменной

  следующего события прокрутки. В
  [`BackToTop`](../../src/pages/current-tasks/ui/BackToTop/BackToTop.tsx)

- Значение интенсивности подсветки общее для кнопок страницы. Описание
  двух состояний заливки синхронизировано со спецификацией и своим пунктом
  в [дизайн-системе](../../docs/design/design-system.md).

индекса. Состояние индекса сохранено.
