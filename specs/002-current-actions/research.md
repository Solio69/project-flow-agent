# Проверенные технические решения

- Для просмотра используем `Vault.cachedRead`. События Vault обрабатываются
  для исходной заметки и связанных файлов, которые влияют на отображение.
- Wikilinks разрешаются по API Obsidian относительно исходного файла.
  Ссылка на отсутствующий файл остаётся текстом с диагностикой. Для навигации
  открываем конкретный разрешённый файл, чтобы действие не создавало заметку.
- Zod Mini из установленного пакета Zod проверяет даты ISO и ID задач. В сборку
  входят используемые схемы. Чистый парсер сохраняет порядок и номера строк.
  Ошибка даты не прерывает разбор списка.

[Vault API](https://docs.obsidian.md/Plugins/Vault) · [Zod API](https://zod.dev/api)
