# Проверить просмотр текущих действий

1. В VS Code запусти `dev:obsidian` из панели NPM Scripts. Дождись сборки.
2. В Obsidian нажми кнопку «Текущие действия» на левой ленте. Если открыт
   предыдущий каркас, перезагрузи плагин или включи Hot Reload.
3. Сверь период, порядок проектов, текст и галочки с заметкой. В незакреплённых
   «Текущих действиях» перейди по названию задачи и заголовку проекта.
   После каждого перехода нажми «Назад» и проверь, что список вернулся.
4. Закрепи «Текущие действия» через меню вкладки. Повтори клики и проверь,
   что каждая заметка открывается в новой активной вкладке, а список остаётся
   открытым. Открепи список и проверь открытие в новой вкладке нажатием
   колёсика и Ctrl+кликом (Cmd+кликом на macOS).
5. Проверь обновление после обычной ручной правки исходной заметки.

`npm test` запускает автоматические проверки. `npm run build` собирает
установочные файлы в `dist/`.
