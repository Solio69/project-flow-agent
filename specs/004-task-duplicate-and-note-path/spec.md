# Дублирование задач и копирование пути к заметке

**Ветка** `feature/duplicate-task-and-copy-path-to-note`

**Карта проекта** «Текущие задачи», операции над строками задач.

## Согласованный объём

По [макетам](../../docs/design/design-system.md) добавить иконку копирования
у названия задачи и команду «Дублировать задачу» в меню «…». Иконка копирует
полный путь на диске с расширением `.md`. Дублирование создаёт новый
Markdown-файл обычным способом. Из исходной задачи берётся название.

## Сценарии

### US1. Скопировать путь для агента

Для задачи с доступной связанной заметкой иконка копирует её фактический
путь, например `D:\Хранилище\Проект\project inbox\Задача.md`. После записи в буфер
показывается подтверждение. Если файл недоступен или буфер отклонил запись,
пользователь получает сообщение об ошибке.

### US2. Создать копию задачи

По команде из меню создаётся новый файл в `project inbox/` того же проекта.
Заголовок берётся из строки с суффиксом «(копия)», затем «(копия 2)» и далее
при занятых именах. Если видимый заголовок недопустим для имени файла,
основой служит имя связанной заметки. В новом файле новый ID и пустое тело. В списке появляется
строка без галочки рядом с исходной. Для «Сегодня» сохраняется этот список
и принадлежность проекта. После копирования отмеченной задачи новая
показывается среди активных.

## Требования и приёмка

- **FR-001 / SC-001** Скопирован точный полный путь с `.md`, включая
  пробелы, кириллицу и разрешённые частью пути символы. Ссылки и Markdown
  при этом не записываются.
- **FR-002 / SC-002** Новый файл получает новый ID, пустое тело и имя на
  основе видимого названия. Исходная заметка сохраняет содержимое и свойства.
  Обе области экрана и коллизии имён покрыты проверками.
- **FR-003 / SC-003** Проверить подмену ссылки и конфликт записи. Если файл
  создан, повтор команды в открытой вкладке использует уже созданную копию
  при совпадающем ID и завершает добавление строки.

Рамка переключателя выполненных совпадает с рамками соседних кнопок.
При добавлении в «Сегодня» просмотр остаётся у исходной карточки проекта.
