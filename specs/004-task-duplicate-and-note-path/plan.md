# План дублирования задач и копирования пути

1. Переиспользовать создание пустой заметки, проверку проекта и запись строки.
   Добавить вставку после исходной строки и подбор свободного имени.
2. Подключить буфер обмена окна Obsidian. В адаптере сверить адрес файла,
   который сейчас разрешается по ссылке задачи, и получить полный путь
   через файловый адаптер.
3. Подключить команду меню и иконку у названия задачи по обоим макетам.
   Проверить фокус, длинные названия и доступность из обеих областей.
4. Проверить запись на синтетическом Markdown, прогнать Chromium на обеих
   темах, TypeScript, сборку и ревью.
5. В длинном списке проверить добавление в «Сегодня» мышью и клавиатурой
   с сохранением видимой карточки и указателя фокуса в исходном проекте.
6. При ревью воспроизвести смену ID до создания и перед записью ссылки,
   изменение списка во время проверки имени и вызов копирования для
   вложения. Проверить отсутствие лишних записей, повтор с тем же файлом,
   публичные входы модулей и фокус в Chromium. Повторить тесты и сборку.
7. Найти строковые выражения через синтаксическое дерево TypeScript.
   Перевести сборку строк на шаблонные литералы, сверить результат
   тестов, сборки и синтаксис скриптов макетов.

Markdown остаётся источником состояния. Только команда дублирования
записывает данные. Ветка выбрана пользователем.
