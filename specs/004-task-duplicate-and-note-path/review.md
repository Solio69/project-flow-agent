# Ревью дублирования и копирования пути

## Повторное ревью записи и кодстайла

Проверены изменения относительно `2ba7a10`, включая файлы в индексе и
новые файлы рабочей копии.

- Высокая важность. Дублирование продолжалось при смене ID исходного файла
  после проверки. Перед созданием и записью ссылки теперь проверяются
  разрешение ссылки и версия файла с подтверждённым ID. При частичной
  записи повтор использует тот же файл копии.
- Высокая важность. Список мог измениться во время проверки имени уже
  после чтения исходника. Снимок списка проверяется после файловых
  проверок и до создания копии.
- Средняя важность. Адаптер принимал путь вложения. Интерфейс и адаптер
  используют общее правило для Markdown-заметок.
- Кодстайл. Модули действий используют публичные входы и отдельные файлы
  констант. Строковое сложение заменено шаблонными литералами в исходниках,
  тестах и макетах. Правило добавлено в кодстайл и скилл ревью.

Проверен локальный diff относительно `2ba7a10`. Иконка получает полный
путь разрешённого файла через файловый адаптер и пишет его в буфер окна
вкладки. Клик по названию
использует прежний обработчик перехода. Иконка и название остаются
отдельными элементами с клавиатурным фокусом.

Дубликат использует создание пустой заметки и запись ссылки по ID. Папку
назначения определяет проект файла, место в списке определяет выбранная
строка. Проверки файловой системы учитывают ещё не проиндексированные
занятые имена. Если при сохранении исчезает цель исходной ссылки,
операция прекращается. Повтор после частичной записи использует квитанцию
уже созданного файла и сверяет его ID.

При добавлении в «Сегодня» фокус восстанавливается в исходном проекте с
`preventScroll`. Для последней задачи фокус получает кнопка раскрытия
карточки. Возврат из «Сегодня» следует существующему правилу назначения.

Проверены изменённые вызовы, тесты, пробелы и границы FSD. В рабочем
Obsidian требуется пользовательская проверка иконки и буфера обмена.
